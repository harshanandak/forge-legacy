## Lens: scaffolding versus durable value

From the owner's 2026-10-16 lens (brief.md:30–32). Every mistake below carries one of these tags:

- **S — scaffolding.** It exists to make up for weaker agents: ceremony, mandatory stage ladders, prompts that do the agent's thinking, guards against mistakes capable agents no longer make. It goes on the DROP list, or becomes an optional reference-solution block.
- **D — durable.** It stays valuable as agents improve: contracts and schemas, single authority, outcome evidence, trust and limits, discoverability. Keep the behaviour and its test, not the old shape.
- **E — environment.** A real platform trap. Keep it as a tested behaviour inside one owning module, never as advice to agents.

Rule of thumb from the lens: **gates judge outcomes, not process.** A gate may refuse a wrong result: a red test, an unbound head, a lost lease, a missing package file. It may not require a ritual such as a stage order, a test file per commit, stage-exit comments, or a TDD phase being reported.

## 7. Top 10 rules for the new AGENTS.md / CODING_STANDARDS

1. **One authority.** Issue, workflow and run state is written only through the Kernel contract. No backend selector, no compat projection, no second store. *Prevents A1, A2, B7.*
2. **Core knows no workflow.** No stage name, TDD term or PR concept appears in a core schema or API; a boundary test enforces it. *Prevents A5, P1, P2.*
3. **Gates judge outcomes.** A gate measures the shipped artifact or the observable result and returns `PASS|FAIL|INCOMPLETE|NOT_EXECUTED`; "nothing checked" is never PASS. *Prevents B1, B2, P6.*
4. **No tracked bookkeeping artifacts.** No committed file exists only to keep a gate green; no hand-maintained manifests; no committed generated mirrors. *Prevents P6, B3, A4.*
5. **Retirement is total.** Removing a feature removes its names, shims and docs in the same PR; the absence test (§8 list) blocks re-entry. *Prevents A3, §2 remnants.*
6. **Demand before breadth.** A block or harness profile enters with a named consumer, a contract test and an installed-artifact receipt. *Prevents A4, A6, A9.*
