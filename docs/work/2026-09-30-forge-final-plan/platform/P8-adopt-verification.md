# P8: verification of P5's unchecked build-versus-adopt alternatives

Decisions needed: choose the optional experiments at the end; the defaults add no mandatory engine or SaaS dependency.

## Bottom line

1. **Keep Kernel authority native.** GitHub Issues, Linear and Jira are projection destinations, never replacement authorities; D44 already makes that distinction. [read: locked-decisions.md:567-581]
2. **Keep bounded supervision native; offer durable engines as optional consumers.** Temporal, Inngest and Restate need an execution service; their JavaScript SDKs are not standalone durable engines. [external, 2026-10-01; §3]
3. **Correct the license argument.** Temporal is MIT; Restate's SDK is MIT while its server is BSL; Inngest's SDK is Apache-2.0 while its current server uses SSPL with a three-year Apache conversion. These facts permit SDK adapters without making either server a core dependency. [external, 2026-10-01; §§2-3]
4. **OPA and Cedar are real local library options.** Both have WASM bindings; a mandatory policy server is unnecessary. Preserve native protected approvals and use them only for additive policy evaluation. [external, 2026-10-01; §4]
5. **Adopt supply-chain evidence, retain conformance.** Sigstore, npm provenance, SLSA, Scorecard and OSV establish different properties; none proves a Forge block's contract or authority safety. [external; inferred; §5]
6. **Node 24 needs a patch-level decision.** Current Sigstore packages and npm 12 require Node 24.15 or newer; Forge declares Node 24.0. Current compatibility is not established for every allowed Node 24 installation. [ran: metadata; read: package.json]
7. **Prefer Release Please for an optional single-package release-PR recipe.** Changesets remains an alternative when contributors must declare release intent; neither replaces readiness, protected workflow authorization or publish receipts. Both already have catalog entries. [read: lib/plugin-catalog.js:339-355; external; §6]
8. **GitHub merge queue is conditional, not a default pruning justification.** Public repositories must be organization-owned; queued groups need their own checks, and queue execution does not establish a Kernel lease or protected approval. [external, 2026-10-01; §8]
9. **Overturn two blanket fit claims.** Mastra history can work without embeddings; c12 handles layers, environment overrides and schema integration beyond discovery. Keep Forge's provenance memory and compiler for their distinct responsibilities. [external, 2026-10-01; §§9-10]
10. **No deletion savings are proven.** The measured monitor/shepherd comparison scope is 10,070 lines, but scope size is not removable code; most adoption avoids future work. GenAI/MCP telemetry conventions remain Development. [ran; external; §§1, 11-12]
